# Paletas de color — Portafolio IA Engineer

Tres temas intercambiables desde el header (tres puntos de color). La elección se guarda en `localStorage`.

## 1. Nexus Blue (default)

- **Vibe:** alineada al monograma JP — confiable, cloud, backend.
- **Colores:** `#030712` · `#3b82f6` · `#06b6d4`
- **Animación sugerida:** GSAP fade + red neuronal cian/azul
- **Ideal para:** roles Python Backend, plataformas en Azure/AWS

## 2. Carbon Mint

- **Vibe:** terminal / DevOps / automatización.
- **Colores:** `#09090b` · `#10b981` · `#a3e635`
- **Animación sugerida:** GSAP stagger + red neuronal verde
- **Ideal para:** perfil DevOps, CI/CD, infraestructura

## 3. Neural Violet

- **Vibe:** LLM, agentes, productos de IA generativa.
- **Colores:** `#0c0a12` · `#8b5cf6` · `#ec4899`
- **Animación sugerida:** GSAP scroll reveal + red neuronal violeta
- **Ideal para:** IA Engineer, agentes, RAG, OpenAI/Claude

## Stack de animación

| Herramienta | Uso en el sitio |
|-------------|-----------------|
| **GSAP + ScrollTrigger** | Hero stagger, secciones al scroll |
| **Canvas (neural-bg.js)** | Fondo de red neuronal suave, colores por tema |
| *(alternativa futura)* **Motion One** | Micro-interacciones en chips y links |
| *(alternativa futura)* **Lenis** | Scroll suave tipo [portafolio Santiago](https://portafolio-santiago-ramirez-forero.vercel.app/) |
